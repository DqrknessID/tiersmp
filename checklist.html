🛠️ 1. Build & Server Setup
  • Compile Plugin with Gradle
    Run .\gradlew.bat build with Java 21. Verify JAR in build/libs/TierSMP-1.0.0.jar.
  • Start Purpur 1.21.11 Server & Verify Startup Logs
    Run .\gradlew.bat runServer (runs Purpur 1.21.11). Ensure [TierSMP] TierSMP enabled! prints with 0 errors.
🎖️ 2. Tier Progression & Thresholds
  • Default State
    New joining player starts as UNRANKED with 0 score.
  • Promotion to C Tier (50 pts)
    Reach 50 score. Verify promotion chat broadcast and screen Title/Subtitle.
  • Promotion to B Tier (150 pts)
    Reach 150 score. Verify promotion broadcast and health increases to 12 hearts.
  • Promotion to A Tier (300 pts)
    Reach 300 score. Verify health increases to 14 hearts and /einv (9 slots) unlocks.
  • Promotion to S Tier (500 pts)
    Reach 500 score. Verify health increases to 16 hearts, /einv (18 slots) unlocks, Speed I granted.
  • Demotion Flow
    Lower score below threshold. Verify demotion announcement, title, and stat reduction.
  • Tier Capacity Limits
    Test max cap (S: 3, A: 7, B: 10, C: 10). Player reaching score cannot enter if tier is full.
  • S-Tier Score Cap (505) & Demotion Cooldown (60s)
    Score cannot exceed 505. Demoted S player cannot re-enter S within 60 seconds.
⚔️ 3. PvP & Scoring Mechanics
  • Dynamic Kill Score Gains (Math-Scaled)
    Same Tier: +30. Underdog Kill: Base 30 + (Gap × 10). Top-Dog Kill: Base 30 - (Gap × 5), min 5.
  • Dynamic Death Score Losses (Math-Scaled)
    Same Tier: -15. Death to Lower Tier: Base 15 + (Gap × 5) [e.g. S losing to A is only -20, S losing to Unranked is -35]. Death to Higher Tier: Base 15 - (Gap × 3), min 3.
  • Kill Cooldown (Anti-Abuse)
    Kill same player within 5 mins: 0 score awarded with cooldown chat notice.
  • S-Tier Kill Streak Sidebar
    Consecutive kills update sidebar scoreboard (updates every 10s). Resets to 0 on death.
🛡️ 4. Combat Tag & Combat Logging
  • 15-Second Combat Tag
    Dealing or receiving player damage initiates a 15-second combat tag.
  • Combat Log Penalty
    Disconnecting while combat tagged causes instant death, drops items, and broadcasts combat log message.
⚡ 5. Tier Perks & Passive Buffs
  • Max Health Attributes
    UNRANKED/C = 20 HP (10 ❤), B = 24 HP (12 ❤), A = 28 HP (14 ❤), S = 32 HP (16 ❤).
  • Infinite Speed I (S-Tier)
    S-tier has Speed I without particles. Reapplied automatically if removed (every 30s).
  • Configurable XP Multipliers
    B Tier (+25% / 1.25x), A Tier (+50% / 1.5x), S Tier (+100% / 2.0x double XP). Configurable in config.yml.
  • Configurable Potion Duration Multipliers
    B Tier (+25% / 1.25x), A Tier (+50% / 1.5x), S Tier (+100% / 2.0x double duration). Configurable in config.yml.
  • Tournament / Fair Event Mode (/tiersmp tournament on|off)
    Temporarily normalizes all players to fair vanilla stats (10 hearts, 0 buffs, 1.0x XP/Potions, locked /einv) for weekly events.
🎒 6. Extra Inventory (/einv)
  • Access Permission
    Denied for UNRANKED/C/B. Allowed for A Tier (9 slots) and S Tier (18 slots).
  • Item Persistence
    Items stored in /einv persist across closing and reopening.
  • Death Drop
    On player death, all items in extra inventory drop on the ground. /einv is emptied.
  • Tier Downgrade Auto-Lock
    If demoted while /einv is open, GUI auto-saves and closes with lock message.
💬 7. Player & Admin Commands
  • /tier & /tier [player]
    Displays tier info: Tier, Score, Kill Streak, Server Rank.
  • /tiertop
    Displays Top 10 leaderboard with ranks, scores, and tiers.
  • /tierscore give <player> <amount>
    Transfers score. Blocked if in combat, self-transfer, or insufficient score.
  • /tieradmin set, setscore, givescore
    Admin tier and score adjustment commands (with automatic promotion status notes).
  • /tieradmin listtier [tier]
    View all players grouped by tier, or inspect players in a specific tier (e.g. /tieradmin listtier S).
  • /tieradmin checklimit
    Check current player counts vs max capacity caps for each tier and active S-demotion cooldowns.
  • /tieradmin clearcooldown <player>
    Instantly clear the 60s S-demotion cooldown for testing promotions without waiting.
  • /tieradmin clearkillcooldown & /tieradmin togglekillcooldown
    Clear 5m PvP kill cooldowns or disable kill cooldown completely for rapid PvP testing/debugging.
  • /tiersmp debug & /tieradmin debug
    Toggle real-time live chat debug feeds (damage, combat tag, kill gap math, score updates, tier changes, and einv logs).
  • /tieradmin recalculate
    Force server-wide tier recalculation, re-sorting all players by score into tier caps.
  • /tieradmin reset & resetall
    Reset individual player data or all server data with 10s confirmation.
  • /tieradmin reload
    Hot-reloads config.yml and messages.yml without server restart.
  • /einvsee <player>
    Admin GUI inspection and editing of another player's extra inventory.
💾 8. Persistence & Integrations
  • Periodic Auto-Save & Server Restart
    Data saves every 5 mins to players.yml. Fully preserved across server restarts.
  • Score Decay Task
    2% score decay every 24h across all players (online & offline).
  • PlaceholderAPI (PAPI)
    Check %tiersmp_tier%, %tiersmp_score%, %tiersmp_streak%, %tiersmp_rank%.
  • Disabled Worlds
    Ensure benefits, score gains, and /tierscore are suppressed in disabled worlds.
